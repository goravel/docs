让更多开发者发现你的扩展包

为你的仓库添加 goravel-package 主题。

  1. 在 GitHub 上，导航至仓库的主页。
  2. 在页面右上角，“关于”右侧，点击齿轮图标（设置）。
  3. 在“主题”下，开始输入你想添加到仓库的主题，以显示匹配主题的下拉菜单。
  4. 点击你想添加的主题，或输入以创建新主题。 例如：goravel-package、goravel 及其他相关关键词。
  5. 点击 保存更改 — 这将使你的软件包更易被发现。
